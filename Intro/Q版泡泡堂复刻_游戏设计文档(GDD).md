## 1. 执行摘要

### 1.1 一句话概述

> 一款 **Q 版卡通风格的 2D 网格休闲竞技游戏**：玩家操控圆润可爱的小角色，在迷宫般的世界里放置"泡泡炸弹"炸开障碍、击败对手，比拼谁更能活到最后。

### 1.2 游戏类型

益智休闲 / 策略竞技（Puzzle-Strategy / Casual Arena）

### 1.3 目标平台

- **首选**：PC（键盘操作，还原经典手感）
- **次选**：Web（H5 / Canvas，浏览器直接运行）
- **后续**：移动端（触控 + 虚拟摇杆）

### 1.4 目标受众

| 维度 | 描述 |
|---|---|
| 年龄 | 10–35 岁，主力 15–25 岁 |
| 性别 | 男女均衡 |
| 游戏经验 | 轻度到中度休闲玩家，熟悉基础键盘操作即可上手 |
| 平台习惯 | 习惯浏览器小游戏、休闲竞技类游戏的玩家 |
| 核心诉求 | 轻松解压、社交娱乐、怀旧情怀、碎片化时间体验 |

### 1.5 独特卖点（USP）

1. **零门槛上手**：4 方向键 + 1 个放泡泡键，3 分钟即可学会。
2. **策略深度**：看似简单的放泡操作，背后有走位、封路、诱敌、道具博弈等多层策略。
3. **双人同屏 PK**：本地双人竞速对战，复刻经典"叫好友来一局"的社交体验。
4. **关卡任务制**：单人模式有 20+ 关递进、多场景主题、多难度，提供长期可玩性。
5. **轻量离线**：无需注册登录，打开即玩，适合碎片时间。

### 1.6 设计支柱（Design Pillars）

| 支柱 | 描述 | "做"的示例 | "不做"的示例 |
|---|---|---|---|
| **快速上手** | 操作极简，规则一目了然 | 新玩家 1 分钟内开始游戏 | 不堆复杂菜单和繁琐前置流程 |
| **策略博弈** | 放泡位置、走位、道具选择构成深度 | 三角封泡、诱导敌人自爆等高级技巧 | 不做纯拼数值碾压的无脑模式 |
| **Q 版治愈** | 圆润角色、明亮配色、欢快音效 | 角色被炸时变成泡泡被困的搞笑演出 | 不做血腥、暗黑或写实风格 |
| **社交同乐** | 支持双人本地对战和分数排行榜 | 双人共享一台设备 PK | 不做强制社交绑定或冗长注册流程 |
| **持续可玩** | 多关卡、多角色、多模式循环推进 | 20+ 关卡 + 4 大主题场景 + 角色解锁 | 不做"通关即死"的线性流程 |

> 本文档描述的是**玩法机制与原创美术方向的复刻蓝图**。所有角色形象、名称、美术资源、音乐音效均为**原创替代方案**，不得直接使用原版 IP 形象、名称或素材。玩法机制（放泡、十字爆炸、道具）属于思想范畴，可借鉴；具体表达需原创。

## 2. 游戏概述

### 2.1 游戏背景故事（轻量设定）

泡泡村是一个充满活力的卡通小社区，住着一群头大身小、性格各异的可爱小动物/食物拟人角色。村子里有一条不成文的传统：每年举行一次"泡泡大赛"，参赛者要用自己吐出的泡泡炸开村中的障碍方块，击败所有对手，成为当年的泡泡之王。

> 本故事仅用于角色世界观包装，**不影响核心玩法**。

### 2.2 游戏流程总览

```
主菜单 → 模式选择 → 难度/人数设置 → 角色选择 → 关卡加载 → 对局进行 → 结算/下一关
                                    ↑                              ↑
                             角色装扮/解锁                   失败重试/下一关
```

### 2.3 核心体验目标

玩家应该感受到：**紧张又轻松**、**上手容易但精通难**、**每一次放泡都心跳加速**。

## 3. 核心玩法循环

### 3.1 单人循环（关卡模式）

```
探索地图 → 炸开障碍方块 → 拾取掉落道具 → 强化能力 → 躲避/击败敌人 → 达成关卡目标 → 结算评分 → 进入下一关
```

### 3.2 双人 / 对战循环

```
选择对战模式 → 放置泡泡炸障碍 → 用道具强化自己 → 用泡泡击败对手 → 比拼生存时间/击杀数 → 胜负结算
```

## 4. 关键机制（Verbs）

| 动词 | 描述 | 输入 |
|---|---|---|
| **移动** | 四方向网格移动角色 | 方向键 / WASD |
| **放泡** | 在当前格子放置一枚泡泡炸弹 | 空格 / Enter |
| **拾取** | 走过道具时自动拾取生效 | 无（被动） |
| **躲避** | 通过走位避开水柱爆炸范围 | 方向键 |
| **使用道具** | 主动型道具（喷火、冰冻等）触发效果 | 特定键 / 自动 |
| **复活/逃脱** | 泡封状态下等待队友营救或计时逃脱 | 无（被动） |

## 5. 系统详解

### 5.1 地图系统

#### 5.1.1 地图结构

- **网格化地图**：固定格子大小（推荐 32×32 像素/格），地图尺寸通常为 **13×11 格** 或 **15×13 格**（奇偶格设计保证通路）。
- **三层结构**（从下到上）：
  1. **地形层**：固定不可破坏的硬墙（棋盘式分布，确保有通路）
  2. **方块层**：可破坏的软方块（随机生成或关卡预设）
  3. **实体层**：角色、泡泡、道具、水柱等动态实体

#### 5.1.2 地形类型

| 地形类型 | 是否可破坏 | 是否阻挡移动 | 是否阻挡泡泡水柱 | 视觉表现 |
|---|---|---|---|---|
| **硬墙（Hard Block）** | ❌ 不可破坏 | ✅ 阻挡 | ✅ 阻挡 | 深色/固定纹理的实心方块 |
| **软方块（Soft Block）** | ✅ 可炸毁 | ✅ 阻挡 | ✅ 阻挡 | 彩色水果/食物方块，炸开有碎片动画 |
| **空地（Floor）** | — | ❌ 通行 | ❌ 通行 | 浅色地面，可能有装饰图案 |

#### 5.1.3 硬墙布局规则

为保证地图一定有通路，硬墙采用**棋盘式（Checkerboard）**布局：
- 所有**偶数行偶数列**交点放置硬墙
- 其余位置可为空地或软方块
- 这样保证任何空地格都至少有两个相邻通路口

#### 5.1.4 地图生成算法（程序化 + 预设混合）

- **预设关卡**：前几关使用手工设计的小地图，保证新手友好
- **程序化生成**：后续关卡使用算法生成（详见 7.2）
- **主题变体**：同一套算法配合不同配色和装饰，产出不同"场景"的地图

#### 5.1.5 场景主题（视觉包装，不影响玩法）

| 主题名称 | 配色方案 | 软方块外观 | 地面装饰 |
|---|---|---|---|
| **果园** | 绿+黄+橙 | 西瓜/橙子 | 小草丛、蝴蝶 |
| **沙滩** | 蓝+白+黄 | 椰子/贝壳 | 海浪纹理、太阳 |
| **雪原** | 白+浅蓝+灰 | 草莓/糖果 | 雪花粒子、冰纹 |
| **玩具城** | 红+蓝+黄 | 积木/玩偶 | 齿轮、弹簧 |
| **糖果屋** | 粉+白+巧克力棕 | 巧克力/棒棒糖 | 糖霜纹理、星星 |

### 5.2 泡泡与爆炸系统（核心机制）

#### 5.2.1 角色放置泡泡

- 玩家按下放泡键，在**当前所在格子**放置一枚泡泡
- 泡泡有**放置冷却时间**（默认 0.3 秒，可通过道具缩短）
- 同一格子不能同时存在多枚泡泡
- 角色**不会**被自己刚放置的泡泡立即炸到（有 0.5 秒安全延迟，或要求角色离开该格）

#### 5.2.2 泡泡倒计时

- 默认爆炸倒计时：**2.5 秒**（可调，影响难度）
- 倒计时期间泡泡有缩放/脉动动画，给玩家**清晰的时间反馈**
- 倒计时归零后爆炸

#### 5.2.3 十字水柱（爆炸）生成

爆炸时，从泡泡中心向**四个方向（上、下、左、右）**各延伸一段距离，形成十字形火焰：

```
      │
      │
  ┌───┤泡泡├───┐
      │
      │
```

- 延伸距离 = **水柱长度** = 基础值 1 格 + 道具加成
- 每个方向最多延伸 **水柱长度** 格
- 遇到以下情况**停止延伸**：
  - 碰到**硬墙** → 立即停止（硬墙不被破坏）
  - 碰到**软方块** → 破坏该方块（可能掉落道具），**停止延伸**（水柱不穿透软方块）
  - 碰到**其他泡泡** → 触发该泡泡也爆炸（**链式反应**），连锁继续
  - 碰到**角色** → 造成伤害，停止延伸
  - 超出地图边界 → 停止

#### 5.2.4 水柱表现

- 水柱为**蓝色半透明流体**覆盖在格子上，持续 **0.5 秒**后消失
- 水柱有**渐隐动画**，给玩家清晰的"危险区域"视觉提示
- 水柱覆盖的格子在持续期间**不可通行**

#### 5.2.5 链式反应

- 水柱碰到另一枚泡泡 → 该泡泡**立即开始爆炸倒计时**（缩短为 0.2 秒），形成连锁
- 连锁可无限传递，但要防止同一帧重复触发（需去重处理）

#### 5.2.6 关键数值（默认值，可调）

| 参数 | 默认值 | 说明 |
|---|---|---|
| 基础水柱长度 | 1 格 | 未吃威力道具时的爆炸范围 |
| 最大水柱长度 | 8 格 | 威力道具上限 |
| 泡泡爆炸延迟 | 2.5 秒 | 放泡后到爆炸的时间 |
| 水柱持续时长 | 0.5 秒 | 火焰可见时间 |
| 连锁反应延迟 | 0.2 秒 | 被触发泡泡的爆炸倒计时 |
| 角色放泡冷却 | 0.3 秒 | 连续放泡的最小间隔 |
| 角色出生安全时间 | 2 秒 | 开局后角色短暂无敌 |
| 受伤无敌时间 | 2 秒 | 被击中后短暂无敌（闪烁） |

### 5.3 道具系统

#### 5.3.1 道具掉落规则

- 软方块被炸毁时有 **概率（默认 30%）** 掉落道具
- 掉落的道具类型**随机**，权重如下（可调）：
  - 炸弹+1：25%
  - 威力+1：25%
  - 速度+1：20%
  - 爱心（回血）：15%
  - 护盾：10%
  - 手套（推泡）：5%

#### 5.3.2 道具类型详表

##### A. 基础永久增益道具（可叠加，死亡保留）

| 道具名 | 图标特征 | 效果 | 叠加规则 | 获取权重 |
|---|---|---|---|---|
| **泡泡+1** | 炸弹图标 | 可同时放置的泡泡数 +1 | 上限默认 8 个 | 25% |
| **威力+1** | 火焰/火苗图标 | 水柱长度 +1 格 | 上限默认 8 格 | 25% |
| **速度+1** | 鞋子图标 | 移动速度 +10% | 可叠加，有视觉变化（跑动特效） | 20% |
| **生命+1** | 红心图标 | 最大生命值 +1 | 上限默认 5 点 | 15% |

##### B. 防御 / 功能道具（一次性，不可叠加）

| 道具名 | 图标特征 | 效果 | 叠加规则 |
|---|---|---|---|
| **护盾** | 盾牌图标 | 抵挡一次爆炸/敌人伤害 | 不能叠加，已有护盾时再吃无效 |
| **手套** | 手套图标 | 可以**推动**已放置的泡泡（踢泡） | 获得后永久可用 |

##### C. 主动型道具（捡到后进入"武器"槽，按特定键使用）

> 这些道具在单人闯关和双人模式中行为不同：
> - **单人模式**：敌人**不能使用**主动道具，只能使用基础增益
> - **双人/对战模式**：敌人可以使用部分主动道具（难度更高）

| 道具名 | 图标特征 | 效果 | 使用方式 |
|---|---|---|---|
| **喷火** | 火焰喷嘴图标 | 向前方 3 格喷射火焰，可引爆炸弹、摧毁方块 | 自动或按键触发，直线范围 |
| **冰冻** | 雪花图标 | 冻结一定范围内敌人 10 秒 | 按键触发，范围 4 格 |
| **手榴弹** |  grenade 图标 | 向**远处**（约 5 格）投掷，可穿透 1 个障碍后爆炸 | 按键触发 |
| **地雷** | 黑色圆点图标 | 在脚下放置地雷，敌人经过时爆炸（自己经过无害） | 按键放置，可被对方泡泡炸毁 |
| **火箭炮** | 火箭图标 | 线性单体伤害，击中第一个目标生效 | 按键发射 |
| **迷惑敌人** | 问号/眩晕图标 | 范围内敌人移动速度减半，持续 5 秒 | 按键触发 |
| **遥控泡泡** | 遥控器图标 | 获得后可用**另一键**手动引爆所有已放置的泡泡 | 按键引爆 |

#### 5.3.3 道具拾取逻辑

- 角色移动经过道具格子 → **自动拾取** → 应用效果
- 拾取时有**弹跳 + 光圈**动画 + **"叮"音效**，提供清晰反馈
- 道具被水柱摧毁 → 消失（不可再次拾取）

#### 5.3.4 道具优先级（同一方块同时掉多个时）

- 采用**随机掉落**，不做优先级排序（保持随机性）
- 也可设计为**每关固定刷一个特殊道具**，增加策略性（参考经典炸弹人设计）

### 5.4 敌人 / AI 系统

#### 5.4.1 敌人基本属性

| 属性 | 默认值 | 说明 |
|---|---|---|
| 生命值 | 1 点（被水柱/道具击中即死） | 简化设计，不做多段血量 |
| 移动速度 | 与玩家基础速度相同 | 可通过难度调整 |
| AI 类型 | 见下方分类 | 不同行为模式 |

#### 5.4.2 AI 行为类型

##### 类型一：随机漫游型（新手友好）

- 随机选择一个方向前进，遇到墙/泡泡时随机转弯
- **70% 概率**：在可移动方向中，有 30% 概率朝玩家方向移动一格
- 简单难度专属，几乎不主动放泡或放泡无脑

##### 类型二：追击型（中等难度）

- 使用 **BFS（广度优先搜索）** 计算到玩家的最短路径
- 每移动几步重新计算一次路径（避免每帧重算，节省性能）
- 接近玩家时尝试放泡（有冷却）
- 放泡后会**快速远离**自己的泡泡（向最近的通路走）

##### 类型三：战术型（困难难度）

- 在追击型基础上增加：
  - **逃生意识**：检测到自身泡泡倒计时 < 1 秒时，优先找最远通路逃跑
  - **道具贪婪**：优先路径规划中会经过道具的格子
  - **封路预防**：避免把自己困在死胡同（BFS 检测四周连通性）
  - 可以吃所有道具并**主动使用**主动型道具（喷火指向玩家、冰冻玩家区域等）

#### 5.4.3 敌人放泡逻辑（战术型）

```
当满足以下条件时，敌人放泡：
1. 身边有可破坏的方块（有道具可拿）
2. 放泡后自己有 ≥ 2 格的逃生路线
3. 不在水柱即将覆盖的格子里
```

#### 5.4.4 AI 性能考虑

- **路径计算频率**：不是每帧计算，而是每 0.5~1 秒或移动一定距离后重新规划
- **寻路算法**：BFS 足够（网格地图，无权图），A* 过度设计
- **视野限制**：AI 只考虑自身格子周围的 8 格范围

#### 5.4.5 机器人对手（移动端版本提及）

- 部分版本支持选择**机器人**作为关卡对手
- 机器人 = AI 的另一种表现形式，行为逻辑相同，外观为机械风格角色

### 5.5 生命 / 泡封系统

#### 5.5.1 生命值

- 玩家初始生命值：**3 点**
- 生命值上限：**5 点**（可通过道具提升）
- 生命值为 0 → 本局失败

#### 5.5.2 被水柱击中

- 角色被水柱覆盖 → **失去 1 点生命**
- 失去生命后：
  - 进入 **2 秒无敌闪烁状态**
  - **清空当前持有的所有临时增益**（主动道具放回，基础增益保留——简化设计，不做细分）
  - 角色**被泡泡困住**（泡封状态），无法主动移动
  - 生命值归 0 → 本局失败

#### 5.5.3 泡封（被困）状态

- 被水柱击中后，角色**被困在一个泡泡里**（视觉上角色缩小并出现在透明泡泡中央）
- 泡封持续 **5 秒** → 自动解除（角色恢复，回到原位置）
- **队友/对手可以营救**：走到泡封角色旁边 → 自动消耗 1 秒 → 解除泡封，角色获得 **2 秒无敌**
- 护盾可以在此时**抵消一次伤害**，避免进入泡封

#### 5.5.4 死亡与复活

- **单人闯关模式**：生命归 0 → 本关失败 → 可重试（保留已解锁进度）
- **双人/对战模式**：一方生命归 0 → 该方淘汰 → 另一方继续（或判定胜负）
- **生存模式**：持续生成敌人，活到最后即胜利

### 5.6 模式与关卡系统

#### 5.6.1 模式总览

| 模式 | 描述 | 玩法目标 | 适合人群 |
|---|---|---|---|
| **单人闯关** | 选择难度，逐关推进 | 在限定时间内达成关卡目标 | 休闲玩家、怀旧玩家 |
| **双人本地 PK** | 两台设备/同一键盘双人 | 消灭所有对手或比拼生存 | 朋友间娱乐 |
| **生存模式** | 无限刷敌，活到最后 | 存活时间最长者胜 | 硬核玩家 |
| **收集模式** | 收集指定数量的道具/星星 | 收集齐所有目标道具 | 探索型玩家 |
| **涂色模式** | （致敬原版）自由涂鸦地图 | 无战斗，纯放松 | 所有玩家 |

#### 5.6.2 单人闯关 — 难度设置

| 难度 | 敌人 AI 等级 | 敌人可吃道具 | 敌人移动速度 | 时间限制 | 关卡数 |
|---|---|---|---|---|---|
| **简单** | 随机漫游 | ❌ 不能 | 基础 | 有（宽松） | 15 关 |
| **一般** | 轻度追击 | ✅ 基础增益 | 基础 | 有 | 20 关 |
| **困难** | 战术型 | ✅ 所有道具 | +20% | 严格 | 25 关 |

#### 5.6.3 单人闯关 — 关卡目标类型

每个关卡有一个**主要目标 + 可选收集目标**：

| 目标类型 | 说明 | 示例 |
|---|---|---|
| **消灭所有敌人** | 炸死/逼出所有敌人即胜利 | "消灭全部 5 个敌人" |
| **限时收集** | 在时间内收集指定数量道具 | "收集 100 枚硬币" |
| **收藏任务** | 收集地图上所有特定道具 | "集齐所有星星" |
| **冰冻任务** | 用冰冻道具冻结指定数量敌人 | "冰冻 10 个敌人" |
| **生存通关** | 在限定时间内存活并到达出口 | "120 秒内到达绿色出口" |

#### 5.6.4 关卡进度与评分

- 每关结束按以下**加权评分**：
  - **爆破分**：炸毁软方块数量 × 10 分
  - **击杀分**：消灭每个敌人 × 500 分
  - **时间分**：剩余时间 × 5 分（时间越宽松，这部分占比越低）
  - **道具分**：拾取每个道具 × 50 分
- 总分累计 → 解锁**新角色**和**新装扮**（参考原版星星解锁机制）
- 最高分**本地保存**，支持分数排行榜（单机版）或在线排行榜（联网版）

#### 5.6.5 程序化关卡生成算法

```
生成关卡(mapWidth, mapHeight, difficulty):
  1. 初始化全空地
  2. 放置硬墙（棋盘式：偶数行偶数列）
  3. 随机填充 60-70% 的空地为软方块
  4. 确保出生点周围 3x3 区域为空地（玩家/敌人安全区）
  5. 确保至少有一条路径连接所有空地（BFS 检查，不够连通则补充）
  6. 按难度调整软方块密度（简单 50%，一般 65%，困难 75%）
  7. 返回地图数据
```

> 手工设计的前 3-5 关使用固定地图，保证新手体验流畅；后续关卡使用上述算法生成。

### 7.1 世界结构

### 7.2 程序化关卡生成（详细算法）

见 5.6.5，此处补充细节：

- **地图尺寸**：推荐 13×11 格（奇数×奇数，保证硬墙棋盘式布局有通路）

### 10.4 关键算法伪代码

#### BFS 寻路（敌人 AI）

```python
def bfs_start(grid, start, goal):
    queue = [start]
    visited = {start}
    parent = {start: None}
    
    while queue:
        current = queue.pop(0)
        if current == goal:
            # 回溯路径
            path = []
            node = current
            while node != start:
                path.append(node)
                node = parent[node]
            path.reverse()
            return path
        
        for neighbor in get_walkable_neighbors(grid, current):
            if neighbor not in visited:
                visited.add(neighbor)
                parent[neighbor] = current
                queue.append(neighbor)
    
    return None  # 无路径
```

#### 水柱计算（爆炸传播）

```python
def calculate_explosion(bomb_pos, flame_length, grid):
    flames = []  # 所有被水柱覆盖的格子
    
    directions = [(0,1), (0,-1), (1,0), (-1,0)]  # 上下左右
    
    for dx, dy in directions:
        for step in range(flame_length):
            x, y = bomb_pos.x + dx * step, bomb_pos.y + dy * step
            
            if not in_bounds(grid, x, y):
                break
            
            tile = grid[x][y]
            
            if tile == HARD_BLOCK:
                break  # 硬墙阻挡，不穿透
            
            flames.append((x, y))
            
            if tile == SOFT_BLOCK:
                break  # 软方块被摧毁，水柱不穿透
            
            # 检查是否碰到其他泡泡 → 触发链式反应
            if there_is_bomb_at(grid, x, y):
                trigger_chain_reaction(x, y)
                break
            
            # 检查是否碰到角色 → 记录伤害
            if there_is_player_at(grid, x, y):
                damage_players.append((x, y))
                break
        
        # 检查是否碰到角色（炸弹中心格）
        if there_is_player_at(grid, bomb_pos.x, bomb_pos.y):
            damage_players.append(bomb_pos)
    
    return flames
```

| 火火（威力） | 2.5 | 1 | 1 | 3 |
| 胖胖（坦克） | 2.5 | 1 | 1 | 4 |
| 毛毛（均衡+） | 3.2 | 1 | 1 | 3 |
| 冰冰（速度+） | 3.5 | 1 | 1 | 3 |
| 果果（均衡+） | 3.0 | 1 | 1 | 3 |
| 铁铁（坦克+） | 2.8 | 2 | 1 | 4 |

> 移动速度可通过"速度+1"道具提升 10% 每级。

### 11.2 道具数值效果

| 道具 | 数值变化 | 上限 |
|---|---|---|
| 泡泡+1 | 可放泡泡数 +1 | 8 |
| 威力+1 | 水柱长度 +1 格 | 8 |
| 速度+1 | 移动速度 ×1.1 | 8 |
| 生命+1 | 最大生命 +1 | 5 |
| 护盾 | 获得 1 次护盾 | —（不叠加） |
| 手套 | 解锁推泡能力 | —（一次性解锁） |

### 11.3 难度平衡表

| 参数 | 简单 | 一般 | 困难 |
|---|---|---|---|
| 敌人 AI 等级 | 1（随机） | 2（轻度追击） | 3（战术） |
| 敌人速度 | 2.5 格/秒 | 3.0 格/秒 | 3.5 格/秒 |
| 敌人可吃道具 | ❌ | ✅ 基础 | ✅ 全部 |
| 软方块密度 | 50% | 65% | 75% |
| 时间限制 | 宽松（+50%） | 标准 | 严格 |
| 敌人放泡频率 | 极低 | 低 | 中等 |
| 初始敌人数量 | 2-3 | 3-5 | 5-8 |

### 11.4 策略可行性检查

- **❌ 避免主导 Build**：不能让"无限泡泡+无限威力"成为唯一必胜解法。设置上限 + 逃生风险自然平衡。
- **✅ 软克制**：速度高的敌人难以被锁定，威力高的泡泡覆盖广但放泡后逃生难。
- **✅ 多玩法并存**：走位流、封路流、道具流、诱导流都可行，没有唯一最优解。

## 12. 开发计划与里程碑

### 12.1 开发阶段

| 阶段 | 时长 | 交付物 | 完成标准 |
|---|---|---|---|
| **P0 — 核心原型** | 2-3 周 | 可玩的最小版本 | 单人模式能跑通：移动→放泡→炸方块→死掉→重生 |
| **P1 — 完整单模式** | 3-4 周 | 单人闯关 10 关 + 3 难度 | 完整核心循环，3 难度可通关，评分系统工作 |
| **P2 — 双人+AI增强** | 2-3 周 | 双人 PK + 敌人 AI 三级 | 双人本地对战可玩，敌人有追击和战术行为 |
| **P3 — 道具+内容扩展** | 3-4 周 | 全部道具 + 20+ 关 + 5 场景 + 8 角色 | 内容量达标，角色可解锁 |
| **P4 — 打磨+UI** | 2-3 周 | 完整 UI、音效、特效、新手引导 | 流程顺畅，反馈到位，无明显 bug |
| **P5 — 测试+优化** | 2 周 | 性能优化、平衡微调、bug 修复 | 60FPS 稳定，各难度可玩可胜 |

## 13. 风险评估

| 风险 | 等级 | 描述 | 应对策略 |
|---|---|---|---|
| **手感难复刻** | 🔴 高 | 炸弹人/泡泡堂的核心魅力在于"放泡的爽感"，是最难还原的部分 | 早期 P0 阶段就投入手感调试，多参考经典作品的移动加速度、放泡冷却、爆炸反馈参数 |
| **AI 不够聪明** | 🟡 中 | 敌人如果太笨会无聊，太聪明会劝退新手 | 三级 AI 分级，简单难度故意"弱"，给新手正反馈 |
| **关卡重复感** | 🟡 中 | 程序化生成的地图可能显得千篇一律 | 多主题皮肤 + 不同软方块密度 + 手工关卡的节奏变化 |
| **性能问题** | 🟢 低 | 粒子特效 + 多实体 + 寻路可能掉帧 | 早期设定性能预算，寻路降频，粒子对象池 |
| **版权风险** | 🔴 高 | 直接复用原版 IP、美术、音乐可能侵权 | 全程原创替代，名称、角色、美术、音频全部原创；玩法机制可借鉴（思想不受保护） |
| **范围蔓延** | 🟡 中 | 想做的功能太多，工期失控 | 严格按 P0-P5 阶段交付，每个阶段有明确完成标准，不提前开干下一阶段 |

### 14.3 关键设计决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 地图尺寸 | 13×11 格 | 经典炸弹人尺寸，手感经过验证 |
| 爆炸延迟 | 2.5 秒 | 给玩家足够的走位时间，又不至于太慢 |
| 水柱长度 | 基础 1 格 | 防止一放泡就清场的无脑体验 |
| AI 算法 | BFS | 网格地图 + 无权图，BFS 足够且实现简单 |
| 道具掉落率 | 30% | 保证有道具可拿，又不至于太富 |
| 生命值 | 3 点 | 宽容但不滥交，死亡有代价 |
| 平台首选 | PC + Web | 还原经典键盘操作体验，浏览器零安装 |
