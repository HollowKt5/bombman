# Q版泡泡堂复刻 — 美术风格设计文档 v1.0

> **文档目的**：为开发团队和美术师提供一套**高性能、高表现力、高还原度**的视觉规范，让复刻版 Q 版泡泡堂的美术风格尽可能接近原版，同时适配手机 + 电脑双端。
>
> **核心原则**：**性能优先，表现次之，还原为本**。在 60FPS 流畅运行的前提下，最大化还原原版的 Q 萌质感和色彩氛围。

---

## 1. 整体美术方向

### 1.1 风格关键词

```
Q版圆润 / 低多边形偏卡通 / 扁平化带微渐变 / 高饱和明快 / 节奏感强 / 零血腥
```

### 1.2 参考锚点

- **原版参考**：Nexon《泡泡堂》Q版角色（头大身小、圆润线条、呆萌大眼）、明快的高饱和配色、扁平化场景
- **性能参考**：《水果忍者》《Bombermine》《BombSquad》——同为休闲炸弹人类，但用矢量/程序化渲染做到移动端 60FPS
- **风格平衡**：保留原版"萌"的核心气质，但用**程序化矢量 + 轻量粒子**替代原版位图素材，体积降 80% 以上，加载快、适配好

### 1.3 视觉层级（从大到小）

| 层级 | 内容 | 优先级 |
|---|---|---|
| 背景层 | 场景主题背景（森林/沙滩/糖果…） | ★★★☆☆ 不能抢主体 |
| 地形层 | 固定墙、可炸砖块 | ★★★★☆ 必须有清晰辨识 |
| 实体层 | 角色、泡泡、道具、爆炸水柱 | ★★★★★ 一切视觉焦点 |
| 特效层 | 爆炸粒子、吃道具反馈、泡封泡泡 | ★★★★☆ 提升爽感 |
| UI层 | 血量、道具栏、得分、菜单 | ★★★★☆ 清晰可读 |

## 2. 角色设计规范

### 2.1 通用角色模板（所有角色共享）

```
头身比：2.5 : 1（头占身高的 40%）
轮廓：圆角矩形/圆形，无尖角
线条：2px 圆角描边，统一深棕/深蓝色
配色：身体主色 + 暗部色（同色相 20% 变暗）+ 亮部色（同色相 15% 变亮）
表情区：眼睛（占头部 30% 面积）+ 嘴巴（2-3px 弧线）+ 可选腮红
肢体：短粗四肢，末端圆形手/脚，无手指细节（保持 Q 萌）
动画状态：idle / walk / placeBomb / explosionHit / win / lose / bubble(泡封)
```

- **每帧动画仅需 2 张图**：idle（1 张）+ walk（腿交换 1 张），靠引擎 sprite swap 或骨骼微动实现行走

## 3. 场景与地图设计

### 3.1 地图单元规范

```
格子大小：48px（逻辑），渲染时按屏幕 DPR 缩放
层结构（从下到上）：
  ① 地板：程序化生成的方格纹理，每格 8px 内描边
  ② 固定墙：深棕色石块，带 1px 高光顶部 + 1px 暗部底部
  ③ 可炸砖：暖黄色砖块，交叉纹理，炸后有碎裂动画
  ④ 装饰：随机散布的小草/石头/花（低概率，纯装饰，不占碰撞）
```

### 3.2 五大大主题场景

| 场景 | 地板色 | 墙色 | 砖块色 | 氛围 | 代表色调 |
|---|---|---|---|---|---|

| **沙滩** | #F4D58D 沙黄 | #8B6914 枯木 | #B8860B 琥珀 | 海边微风 | 黄+蓝+白 |
| **糖果** | #FFB6C1 粉 | #FF69B4 热粉 | #FFD700 糖黄 | 甜蜜梦幻 | 粉+紫+白 |
| **雪原** | #E0F7FA 冰蓝 | #90A4AE 雾灰 | #B0BEC5 雪白 | 清冷纯净 | 蓝+白+青 |
| **夜市** | #2C2C54 深蓝 | #1A1A3E 暗紫 | #FF6B6B 红灯 | 热闹喧嚣 | 紫+红+黄 |

> 💡 **程序化背景**：每个场景用 2-3 个全屏色 + 程序化噪声生成背景装饰（树叶剪影/浪花/糖果糖霜/雪花/灯笼），无需大量位图素材，性能极佳

### 3.3 地图布局规则

```
可玩区域：矩形 13x11 格 ~ 15x13 格（随关卡变化）
边界：最外圈固定墙（不可破坏）
内部：
  - 1/4 概率放置固定墙（形成天然屏障和路线）
  - 剩余空地 70% 概率生成可炸砖
  - 保证至少 2 条通路（用 BFS 校验连通性，不通则重新生成）
  - 道具出生点：空旷区域随机 3-5 个位置
```

## 5. 特效与粒子规范

### 5.1 爆炸表现（玩法灵魂，必须爽）

```
爆炸水柱（横向/纵向延伸）：
  - 主体：半透明蓝白色方块，从格子中心向两端延伸
  - 边缘：1px 亮蓝描边 + 轻微内发光
  - 动画：0.15s 内从 0 扩大到全格，0.15s 维持，0.2s 缩没 → 总时长 0.5s
  - 粒子：沿水柱方向喷射小水珠粒子（10-15个/格），带重力下落

爆炸中心（十字交汇点）：
  - 白色闪光圆（半径 0.5 格）→ 快速扩散到 1.2 格 → 淡出
  - 中心 0.1s 内从全亮到半亮（模拟冲击波）

受击表现：
  - 角色→泡泡：0.3s 内角色缩小并被半透明泡泡包裹，泡泡有 8 个高光点缓慢旋转
  - 屏幕轻微震动（不超过 2px，避免眩晕）

性能优化：
  - 水柱用 9-slice 缩放的单一纹理，避免每格单独绘制
  - 粒子用对象池，上限 200 个
  - 移动端粒子数 ×0.5，桌面端全量
```

### 5.2 其他特效

| 事件 | 表现 | 粒子数 |
|---|---|---|
| 放泡泡 | 泡泡从角色头顶冒出，0.2s 内从 0.3 格涨到 0.5 格，带轻微弹跳 | 5 |
| 吃道具 | 道具旋转缩小吸入角色 + 彩色星屑 | 8 |
| 泡泡寿命到 | 泡泡轻微抖动 → 啪一声消失（无粒子） | 0 |
| 胜利 | 角色跳起 + 周围持续飘落星星/纸屑 | 30/s |
| 失败 | 角色缩小变黑 + 雪花飘落 | 10 |
| 泡封营救 | 营救者碰到的瞬间，被封泡泡碎裂 + 彩色爆发 | 15 |

### 6.1 整体风格

```
字体：圆润无衬线体（系统默认或程序化圆体），禁止细字体
按钮：圆角矩形 + 轻微 3D 浮雕（顶部高光 + 底部阴影）+ 按下时下沉 2px

## 7. 音频设计方向（配合美术，提升整体质感）

> 虽然不在视觉范围，但音频和视觉共同决定"像不像原版"，一并给出方向：

```
音乐：8-bit/chiptune 风格，每场景一首 30-60s 循环 BGM
  - 森林：轻快木琴 + 简单的打击节奏
  - 沙滩：海浪白噪音 + 轻松旋律
  - 糖果：甜美琶音 + 铃铛点缀
音效（每个 0.05-0.1s，低保真 chiptune 合成）：
  - 放泡：短促"咔嗒"（方波 + 快速衰减）
  - 爆炸：噪声 + 低频下扫（simulate 冲击波）
  - 吃道具：上升琶音（3 个音阶快速上行）
  - 受击：下滑音 + 噪音（幽默的"哎呦"感）
  - 胜利：欢快旋律片段 / 失败：低沉下行
```

## 8. 性能预算与优化指南

### 8.1 每帧预算（目标 60FPS @ 60fps tick）

| 资源类型 | 桌面端 | 移动端 | 优化手段 |
|---|---|---|---|
| 活动实体（角色/泡泡/道具） | ≤ 50 | ≤ 30 | 对象池 + 空间分区 |
| 粒子数 | ≤ 300 | ≤ 150 | 池化 + LOD |
|  draw call | ≤ 80 | ≤ 50 | 图集打包 + 批量渲染 |
| 纹理总内存 | ≤ 32MB | ≤ 16MB | 图集 + 尺寸≤512px |
| JS/CPU 每帧 | < 4ms | < 5ms | 固定步长 + 避免 GC |

### 8.2 渲染策略（双端）

```
统一方案：Canvas 2D（Web）或 WebGL（高级）
推荐：WebGL + 图集批渲染（Draw call 最低）
备用：Canvas 2D（兼容性好，足够 4399 版这种复杂度）

纹理压缩：移动端使用 ASTC 4x4 / ETC2，桌面端用 RGBA8
资源规模：全部美术资源 ≤ 8MB（zip 后），加载时间 < 3s
```

### 8.3 关键性能点

- **地图渲染**：只渲染视口内的格子（相机跟随或整屏小地图都只画可见区域）
- **纹理图集**：所有角色帧、道具图标、UI 元素打进 2-3 张图集，避免大量小纹理切换
- **动画降级**：移动端降低粒子质量和阴影精度；桌面端全特效
- **避免实时阴影**：用"假阴影"（角色脚下半透明椭圆）替代实时 shadow map
- **声音懒加载**：BGM 仅在进入关卡时加载，离开时释放

## 10. 开发优先级（美术资源）

```
P0（必做，先出可玩）：
  - 角色 8 个 × 2 帧（idle/walk）= 16 张
  - 地图三要素（地板/墙/砖）各 1 张 + 9-slice 数据
  - 道具 8 种 × 1 张 = 8 张
  - 爆炸水柱 1 套（含粒子纹理 1-2 张）
  - 字体 + 基础 UI 组件 1 套

P1（提升体验）：
  - 场景主题背景 5 套（程序化或半程序化）
  - 角色 8 个 × 额外帧（放泡/受击/胜利/失败）= 32 张
  - 泡封泡泡特效 1 套
  - 虚拟按键 UI 2 套（竖排/环形）

P2（打磨细节）：
  - 角色隐藏版 2 个 × 全套帧
  - 场景装饰物 5 套（程序化生成参数）
  - 高级粒子效果（爆炸碎屑/烟雾/火花）
  - 音效 + BGM（chiptune 合成）

P3（锦上添花）：
  - 角色换装系统（帽子/衣服/表情）
  - 关卡特殊特效（冰原霜花/沙滩浪花/糖果糖屑）
  - 屏幕震动/闪白/慢动作等电影级反馈
```
