# 🫧 泡泡小英雄（BombMan）v1 —— Q 版泡泡堂复刻核心原型

依据 `Intro/` 三份规格文档（[GDD](./Intro/Q版泡泡堂复刻_游戏设计文档(GDD).md) / [美术风格](./Intro/Q版泡泡堂复刻_美术风格设计文档.md) / [代码设计](./Intro/Q版泡泡堂复刻_代码设计文档.md)）实现的**第一个可玩版本**（对应代码文档里程碑 P0–P2 + 轻量 P3）。

- **平台**：Web（PC 键盘为主，移动端附带虚拟按键）
- **技术栈**：TypeScript（ES2020）+ 手写 Canvas 2D + Vite + vite-plugin-singlefile，**零运行时第三方依赖**
- **产出**：单文件 `dist/index.html`，双击即可运行 / 任意静态托管
- **存档**：IndexedDB（最高分，自动回退内存）

---

## 运行

```bash
npm install            # 安装开发期工具（vite / typescript / vitest）
npm run dev            # 开发模式 http://localhost:5173
npm run build          # 产出单文件 dist/index.html（tsc 校验 + vite build）
npm run preview        # 预览构建产物
npm test               # 运行 42 个单元/集成测试（vitest，node 环境）
npm run typecheck      # 仅类型检查
```

## 目录结构（遵循代码文档）

```
src/
├── shared/            公共类型 / 数值常量 / 事件总线
├── core/
│   ├── domain/        纯数据模型 + 工厂（地图生成、实体、GameState）
│   ├── rules/         纯函数规则层（movement / bomb / powerup / damage / ai）
│   ├── systems/       无状态行为模块（move / bomb / explosion / powerup / ai / camera / game-loop）
│   └── services/      接口契约（rng / storage / audio）
├── infrastructure/    SeedRNG / IndexedDB / Web Audio 合成 / 输入路由
├── presentation/      渲染器（地图/实体/粒子/HUD）、键盘/触控输入、DOM UI、app 装配
├── test/              Vitest 单测（rules 对应 + 核心管线冒烟测试）
└── main.ts            入口
```

依赖方向：`presentation → core/systems → core/rules → core/domain → shared`，`infrastructure` 仅实现 `core/services` 接口。

## 已知取舍（v1）

- 单人闯关（5 关）+ 三种难度；双人 PK / 生存模式留待 P2+。
- 主动型道具（喷火/冰冻/手榴弹等）与装扮系统未实现（P3 范围）。
- 泡封营救（队友/对手触碰解除）在单人模式中无意义，未实现；泡封到时自动解除。
- 敌人为 1 血即死（GDD 5.4.1），与玩家 3 血体系分离。
- 移动端为简易虚拟按键（横竖屏强制翻转未做）。
